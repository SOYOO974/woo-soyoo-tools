# Woo SOYOO Tools (`woo-soyoo-tools`)

Extension WordPress/WooCommerce propriétaire **SOYOO** regroupant les améliorations transversales, correctifs natifs et optimisations appliqués à l'ensemble des boutiques WooCommerce gérées par l'agence.

## Points clés

- **Registre modulaire avec activation par défaut intelligente (Opt-Out)** : Toute nouvelle fonctionnalité livrée dans une mise à jour (`default_enabled => true`) s'active automatiquement sur l'ensemble du parc client, tout en respectant les désactivations spécifiques effectuées sur un site donné.
- **Interface d'administration dédiée (`WooCommerce > SOYOO Tools`)** :
  - Recherche instantanée par mot-clé, hook ou identifiant.
  - Filtres rapides par catégorie et par état (`Actives` / `Désactivées`).
  - Interrupteurs AJAX avec sauvegarde immédiate sans rechargement de page.
  - Tiroir de documentation technique intégré à chaque fonctionnalité (Problème, Solution SOYOO, Hooks branchés).
- **Mises à jour automatiques via GitHub Releases** : Intègre *Plugin Update Checker v5* connecté à `SOYOO974/woo-soyoo-tools`.
- **Compatible WooCommerce HPOS** (`custom_order_tables`) & `product_instance_caching`.
